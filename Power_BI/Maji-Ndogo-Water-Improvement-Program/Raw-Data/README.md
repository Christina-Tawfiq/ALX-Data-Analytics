## Data Sources

The project uses multiple datasets provided as part of the ALX Data Analytics Program:

- Md_water_services_data.xlsx (Primary operational dataset)
- Md_queue_related_crime.csv (Crime and queue-related incidents)
- Md_summary.csv (Aggregated reporting dataset)
- UN_SDG_dashboard_data.csv (Sustainable Development Goals indicators)

The datasets were used across different phases of the project, including exploratory analysis, data modeling, executive reporting, budget planning, and project monitoring.

## Data Availability

The dataset used in this project originates from the ALX Maji Ndogo case study.

To respect potential licensing and redistribution restrictions, raw data files are not included in this repository.

All dashboards, documentation, DAX measures, and analysis outputs were developed using the original project dataset.
