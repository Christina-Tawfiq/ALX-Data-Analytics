# Power BI Projects

This folder contains Power BI projects completed as part of the ALX Data Analytics Program.

## Projects

### 💧 Maji-Ndogo-Water-Improvement-Program

An end-to-end Power BI project focused on analyzing water accessibility challenges across Maji Ndogo through interactive dashboards, data modeling, executive reporting, budget planning, and infrastructure improvement analysis.

#### Project Parts

**Part 1 – Exploratory Analysis & Visual Storytelling**
- Water Access Analysis
- Queue Analysis
- Pollution Analysis
- Crime Analysis
- Infrastructure Assessment

**Part 2 – Data Modeling & Interactive Reporting**
- Data Modeling
- Relationship Management
- National Overview Dashboard
- Queue Analysis Dashboard
- Pollution Analysis Dashboard
- Crime Analysis Dashboard

**Part 3 – Executive Dashboard & Budget Planning**
- National Water Access Dashboard
- Provincial Executive Dashboards
- Budget Allocation Analysis
- Required Improvements Analysis
- Water Access KPI Tracking

**Part 4 – Project Monitoring & Transparency**
- Project Progress Tracking
- Budget vs Actual Monitoring
- Vendor Performance Analysis
- Public Transparency Reporting
