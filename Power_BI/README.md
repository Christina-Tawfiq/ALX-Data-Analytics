# Power BI Projects

This folder contains Power BI projects completed as part of the ALX Data Analytics Program.

## Projects

### 💧 Maji Ndogo Water Services Analytics and reporting 

An end-to-end Power BI project focused on analyzing water accessibility challenges across Maji Ndogo through interactive dashboards, data modeling, budgeting, and decision-support reporting.

### Project Parts

#### Part 2 – Data Modeling & Interactive Reporting
Built a Power BI data model and developed interactive dashboards covering:
- National Overview
- Queue Analysis
- Pollution Analysis
- Crime Analysis

#### Part 3 – Executive Dashboard & Budget Planning
Developed strategic dashboards to:
- Measure basic water access
- Estimate upgrade budgets
- Analyze improvement priorities
- Support national and provincial decision-making

#### Part 4 – Project Monitoring & Transparency *(In Progress)*
Focused on:
- Project progress tracking
- Budget vs Actual analysis
- Vendor performance monitoring
- Public transparency reporting
