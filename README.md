# ALX Data Analytics 

This repository contains selected projects and practical work completed during the ALX Data Analytics Programme — 2024.

## 📊 About the Programme
The **ALX Data Analytics Programme (2024)** provided a practical foundation in data analysis, covering the complete process of preparing, querying, analysing, and visualising data.  
The programme focused on developing analytical thinking and practical skills using **spreadsheets, SQL, and Power BI**, with an emphasis on solving real-world data problems and communicating insights effectively.

## 🛠️ Tools & Technologies
- Google Sheets / Spreadsheets  
- SQL  
- Power BI  

## 📚 Programme Content
1. **Explore 101**  
   - Introduction to Data & Data Analysis  
   - Problem-Solving  
   - Programmatic Thinking  

2. **Preparing Data**  
   - Introduction to Spreadsheets  
   - Data Manipulation  
   - Introduction to Statistics  
   - Data Modelling  

3. **Querying Data**  
   - Introduction to SQL  
   - Relational Database Design  
   - SQL in Practice  
   - Data Manipulation  

4. **Visualising Data**  
   - Data in Power BI  
   - Data Visualisation  
   - Dashboard Development  
   - Visual Storytelling  

## 🎯 Skills Developed
- Data preparation and cleaning  
- Spreadsheet-based data analysis  
- Basic statistical analysis

- Relational database concepts

- Power BI data visualisation
